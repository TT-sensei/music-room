# 音源について（出典・ライセンス・加工内容）

このフォルダの音源は、すべてライセンスを確認したうえで収録した実録音サンプルです。
アプリはこれらのファイルをサイト内から読み込むだけで、外部サーバーへの通信は行いません。

## リコーダー（recorder/）

- 音源名：FreePats "Wooden Recorder"（"Venus" 木製リコーダー）
- 演奏・録音：Eugene Vlaskin（FreePats project）。サンプルの加工・整備：roberto@zenvoid.org
- 配布元：https://freepats.zenvoid.org/Wind/recorder.html
- ライセンス：CC0 1.0 Universal（パブリックドメイン相当）
  https://creativecommons.org/publicdomain/zero/1.0/
- 使用ファイル：72_C5.wav 〜 93_A6.wav の17ファイル（SFZ版 "Recorder-SFZ-20201205" の各音サンプル _01 を使用）
- 元音源との関係：各音（C5〜A6のうち17音）をそのままの音程で使用。
  サンプルの無い5音（C#5・D#5・D#6・F#6・G#6）は、隣の音のサンプルを±1半音だけピッチ変換して再生する。
- 加工内容：
  - 48kHz/24bit → 44.1kHz/16bit モノラルに変換
  - 先頭・末尾の無音を除去し、末尾は自然な減衰を残してトリミング（長いものは最大2.3秒）
  - ピーク音量をそろえる正規化、末尾のクリック防止フェード

## 鍵盤ハーモニカ（pianica/）

- 音源名：Hohner Melodica マルチサンプル（Freesound パック "Melodica"）
- 作者：fese
- 配布元：https://freesound.org/people/fese/packs/1425/
- ライセンス：Creative Commons Attribution 4.0（CC BY 4.0）
  https://creativecommons.org/licenses/by/4.0/
  この表示（作者名・出典・ライセンス・加工内容）が帰属表示です。
- 取得方法について：Freesoundの原音WAVダウンロードにはアカウントログインが必要なため、
  同サイトが公開しているプレビュー音源（MP3/OGG）から該当する音の区間を抽出して使用した。
- 音程の検証について：プレビューに実際に含まれていた音は、ファイル名の表記より1オクターブ高い
  C4〜B♭5 の音だった（スペクトル分析で全音を実測して確認）。そのため、ファイル名ではなく
  実測した音程を基準にアンカー音として収録している。プレビューから取得できた実音はここまでで、
  それより低い音（F3〜A3）の実音サンプルは含まれていなかった。
- 使用ファイル：60_C4.wav 〜 82_Bb5.wav の8ファイル（アンカー音）
- 加工内容：
  - 各ファイルから単音の持続区間を切り出し、44.1kHz/16bit モノラル WAV に変換
  - 長押し再生用に、波形の位相が合う区間をループ範囲として設定し、接続部に15msのクロスフェードを適用
  - ピーク音量をそろえる正規化、先頭のクリック防止フェード
- マッピング：鍵盤の各音は、最も近いアンカー音を最大±2半音までピッチ変換して再生する。
  対象は C3（48）〜C6（84）の37音すべて。
- 低音アンカー（2026-11-20追加）：C3・E3・G3・B♭3 の4音は、上記実録音の C4・E4・G4・B♭4 を
  Rubber Band で1オクターブ下げて作成した（長さとフォルマントは保持、ピーク正規化、
  ループ位置は波形相関で再選定）。スペクトル実測で音程のずれは +2.6〜+12.1セント以内を確認。
  これにより、以前はシンセ音だった F3〜A3 を含め、低音域も実録音由来の音色にそろえた。
  鍵盤の下限も F3 から C3 へ広げ、37鍵盤とした（低音パートがそのまま弾けるように）。

## フォールバック

音源ファイルが読み込めなかった場合でもアプリが止まらないよう、
従来のシンセサイザー音で代替再生する仕組みを残しています（通常の利用では使われません）。
